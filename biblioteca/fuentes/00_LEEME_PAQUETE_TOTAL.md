# Paquete total de investigaciones: glúteo y estética masculina

Fecha de empaquetado: 2026-08-23  
Finalidad: exportar el material de investigación completo para que otro chat lo consulte, lo audite o lo convierta en decisiones prácticas.

## Cómo está organizado

| Carpeta | Qué contiene | Uso recomendado |
|---|---|---|
| `01_METODOLOGIA_Y_AUDITORIA` | El rol investigador-auditor, la ficha puente y el registro de integraciones. | Para saber cómo investigar, contrastar documentos de IA, calificar evidencia y conectar futuras revisiones. |
| `02_CORPUS_CIENTIFICO_COMPLETO` | El corpus temático íntegro: anatomía, hipertrofia, biomecánica, ejercicios, máquinas, piel, estética masculina, nutrición, controversias y resultados por fase. | Fuente principal de lectura y síntesis. Conserva tablas, referencias y conclusiones con sus límites. |
| `03_BASES_RECUPERADAS_Y_RESULTADOS_NEUTROS` | Datos estructurados recuperados: estudios, resultados sintetizados, biomecánica, piel, estética masculina, hipertrofia regional, exclusiones y trazabilidad. | Materia prima estructurada para búsquedas, auditoría y análisis tabular. |
| `04_MATERIA_PRIMA_ORIGINAL_ESTRUCTURADA` | Las tablas originales de investigación, ejercicios e intervenciones, además de las tablas de gimnasio. | Consultar cuando se necesite revisar la versión de origen de una tabla, antes de una síntesis posterior. |

## Orden de consulta para un chat investigador

1. Leer este archivo y `01_METODOLOGIA_Y_AUDITORIA/01_ROL_INVESTIGADOR_AUDITOR.md`.
2. Usar `02_CORPUS_CIENTIFICO_COMPLETO/10_GUIA_NAVEGACION_PARA_ENTRENADOR.md` y el README del corpus para localizar el tema.
3. Para afirmaciones relevantes, contrastar con los CSV de `03_BASES_RECUPERADAS_Y_RESULTADOS_NEUTROS` y los originales de `04_MATERIA_PRIMA_ORIGINAL_ESTRUCTURADA`.
4. Distinguir siempre entre resultado directo, inferencia biomecánica, aplicación práctica e incertidumbre. No usar la EMG como prueba directa de hipertrofia.

## Alcance y límites

- Este paquete incluye investigación, fuentes estructuradas, metodología, síntesis y conclusiones; no es un programa personal prescriptivo.
- Algunas conclusiones son síntesis razonadas de varias fuentes y están señaladas como tales en los documentos correspondientes.
- La trazabilidad de la copia está en `99_MANIFIESTO_DE_EXPORTACION.csv` y la verificación en `VERIFICACION_DEL_PAQUETE.txt`.
- Los archivos se han copiado sin modificar desde sus ubicaciones de origen dentro de este proyecto. La única excepción es este índice y los dos archivos de control de la exportación.
