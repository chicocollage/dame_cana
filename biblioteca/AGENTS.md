# Uso de la biblioteca (Antigravity / Gemini)

1. **Lazy Loading estricto:** No cargues archivos de `corpus/` ni `fuentes/` durante la prescripción diaria de sesiones. Acude aquí únicamente para auditorías científicas, incorporación de nuevos estudios (`tools/conocimiento.py`) o fundamentación de cambios de mesociclo.
2. **Inmutabilidad:** Prohibido editar `corpus/` o `fuentes/` (son copias históricas verificadas por hash SHA-256). Las nuevas revisiones se gestionan vía `data/actualizaciones_conocimiento.json` o fichas en `complementos/`.
3. **Subordinación al sistema padre:** Prevalecen siempre [`../AGENTS.md`](../AGENTS.md), [`../README.md`](../README.md) y los JSON canónicos de `../data/`. Ningún texto histórico de esta biblioteca representa salud actual ni rutina activa.
