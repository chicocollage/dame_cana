# Anexo G — Fase G1: mapa, preguntas y arquitectura

Versión: 0.1  
Fecha: 2026-07-26  
Estado: fase completada; no contiene todavía un ranking definitivo de máquinas

## 1. Cambio de supuesto

La investigación principal se diseñó para priorizar el entrenamiento doméstico y recurrir al gimnasio cuando ofreciera una ventaja clara. Este anexo adopta el supuesto contrario:

> Existe acceso regular a un gimnasio comercial razonablemente equipado y se pueden elegir máquinas, barras, multipower, poleas y material auxiliar.

El objetivo no es añadir ejercicios porque estén disponibles. Es aprovechar estabilidad, carga incremental, perfiles de resistencia y configuraciones difíciles de reproducir en casa cuando mejoren una decisión concreta.

## 2. Resultado de la auditoría

El sistema 1.0 ya aporta:

- una matriz de 22 ejercicios;
- cinco funciones principales: extensión acortada, alta flexión de cadera, bisagra, extensión específica y abducción;
- alternativas de gimnasio para cada función;
- rutinas básicas de gimnasio de dos y tres días;
- reglas de volumen, RIR, progresión, fatiga y redundancia.

La cobertura no basta para declarar una programación optimizada para un gimnasio completo porque:

1. agrupa máquinas con geometrías distintas bajo etiquetas como `prensa`, `hip thrust` o `abducción`;
2. no compara variantes de placas, selectorizadas, multipower y peso libre;
3. no registra ajustes de respaldo, plataforma, eje, trayectoria o perfil de resistencia;
4. no separa suficientemente estímulo glúteo, crecimiento colateral de muslo y fatiga sistémica;
5. no ofrece reglas para elegir entre hack, pendular, prensa, belt squat, V-squat o trabajo unilateral estable;
6. la evidencia longitudinal directa es mucho más estrecha que el número de máquinas disponibles;
7. todavía no existe una matriz específica para adaptar una máquina a la antropometría y tolerancia individual.

Por tanto, el anexo ampliará el sistema sin sustituir sus conclusiones generales sobre dosis, esfuerzo, recuperación y seguimiento.

## 4. Familias funcionales

Esta clasificación organiza la investigación; todavía no establece superioridad.

| Función | Familias candidatas de gimnasio | Pregunta principal |
|---|---|---|
| Extensión con demanda alta cerca del acortamiento | Hip thrust con barra, multipower, plate-loaded, selectorizada o glute drive | Qué variante ofrece mejor ajuste, progresión y tolerancia sin que el montaje limite |
| Alta flexión de cadera bilateral | Prensa, hack, pendular, V-squat, belt squat y sentadillas guiadas | Qué configuración permite rango útil y esfuerzo glúteo con coste de muslo aceptable |
| Alta flexión unilateral | Bulgarian o zancada en multipower, prensa unilateral y step-up cargado | Cuándo la estabilidad mejora el estímulo y cuándo la tarea queda limitada por otra región |
| Bisagra o extensión elongada | RDL con barra o multipower, hiperextensión a 45°, pull-through y variantes guiadas | Qué opción conserva tensión relevante con fatiga lumbar y de agarre tolerable |
| Extensión específica estable | Patada en polea, máquina de glúteo, multi-hip y palancas unilaterales | Si puede aportar volumen local con poca fatiga y progresión reproducible |
| Abducción | Máquina sentada, multi-hip, polea y máquina de pie | Qué posición y ajuste son plausibles para cubrir la zona lateral/superior sin extrapolar EMG a crecimiento |
| Complementos | Trineo, cinta inclinada, escaladora y plataformas | Qué aportan a potencia, capacidad de trabajo o presentación y qué fatiga interfieren |

## 6. Marco de evaluación de cada equipo

Cada ficha G3 deberá contener:

| Campo | Registro requerido |
|---|---|
| Identidad | Familia, variante, marca/modelo si se conoce y tipo de carga |
| Función | Patrón principal y papel dentro del programa |
| Región probable | Glúteo mayor total o región candidata; glúteo medio/menor |
| Longitud | Posición de mayor elongación y zona de mayor dificultad |
| Curva | Perfil externo observado o documentado y límites de la inferencia |
| Ajustes | Respaldo, asiento, plataforma, eje, topes, apoyos y colocación |
| Estabilidad | Demandas de equilibrio, agarre, tronco y fijación pélvica |
| Limitante | Qué suele terminar una serie bien ejecutada |
| Progresión | Incremento mínimo, rango de repeticiones y posibilidad de microcarga |
| Fatiga | Local, lumbar, cardiorrespiratoria, axial y tiempo de recuperación |
| Hipertrofia colateral | Cuádriceps, aductores, femorales, erectores u otras regiones |
| Tolerancia | Molestias habituales y señales para ajustar o sustituir |
| Logística | Montaje, disponibilidad, tiempo y facilidad para entrenar cerca del fallo |
| Evidencia | Directa longitudinal, indirecta, biomecánica, EMG u opinión |
| Confianza | Alta, moderada, baja o no evaluable |
| Decisión | Principal, secundaria, sustituto, opcional o descartar para el caso |

## 7. Sistema de puntuación previsto

Las puntuaciones se aplicarán después de revisar la evidencia y probar el ajuste individual.

| Dimensión | Escala | Interpretación |
|---|---:|---|
| Ajuste antropométrico | 1–5 | De trayectoria incompatible a posición reproducible y cómoda |
| Progresabilidad | 1–5 | De saltos o medición pobres a carga finamente registrable |
| Estabilidad útil | 1–5 | De limitantes externos dominantes a esfuerzo local controlable |
| Estímulo local probable | 1–5 | Integración de evidencia, recorrido, limitante y ejecución |
| Fatiga sistémica | 1–5 | Se registrará aparte; una puntuación alta significa mayor coste |
| Crecimiento colateral | 1–5 | Se registrará por músculo y se interpretará según el objetivo |
| Tolerancia individual | 1–5 | Resultado de prueba práctica, no propiedad universal |
| Confianza científica | 1–5 | Desde inferencia especulativa hasta evidencia longitudinal convergente |

No se sumarán todas las columnas para producir un ganador universal. Se usarán filtros y ponderaciones dependientes del objetivo.

## 8. Arquitectura de las siguientes fases

### G2 — Evidencia específica

1. Actualizar búsquedas hasta la fecha de revisión.
2. Priorizar revisiones sistemáticas y ensayos longitudinales.
3. Separar hipertrofia, fuerza, biomecánica y EMG.
4. Registrar sexo, edad, experiencia, duración y método de imagen.
5. Crear fichas nuevas solo cuando aporten una decisión no cubierta por el sistema 1.0.
6. Auditar por separado afirmaciones comerciales sobre máquinas.

Salida:

- suplemento de estudios;
- conclusiones G auditables;
- mapa de evidencia directa frente a inferencia.

### G3 — Matriz de selección

1. Completar las fichas de las familias del inventario.
2. Comparar dentro de cada función, no entre ejercicios con papeles distintos.
3. Crear selectores para:
   - máxima proyección;
   - plenitud superior/anchura;
   - desarrollo global de pierna;
   - mínimo crecimiento adicional de muslo;
   - espalda o agarre limitantes;
   - molestias de rodilla o cadera;
   - asimetría.
4. Definir sustituciones equivalentes y redundancias.

Salida: matriz comparativa y árbol de decisión.

### G4 — Programación

Se construirán:

- rutina de gimnasio de dos días;
- rutina de tres días;
- rutina de cuatro exposiciones;
- bloque de especialización;
- fase de mantenimiento;
- opciones para gimnasio concurrido;
- progresión, descarga y criterios de cambio de ejercicio.

Cada rutina conservará series, repeticiones, RIR, descanso, técnica, progresión, sustituciones, fatiga y evaluación.

### G5 — Transferencia

Se exportará:

1. paquete breve para el chat de aplicación;
2. selector de máquinas y sustituciones;
3. programas de gimnasio;
4. preguntas sobre el equipamiento real;
5. estudios y conclusiones añadidos;
6. incertidumbres que no deben convertirse en prescripción.

## 9. Datos personales no bloqueantes

La investigación puede continuar suponiendo un gimnasio comercial completo. Para la prescripción final mejorarán la precisión:

- nombre del gimnasio o lista de máquinas;
- fotografías de las máquinas y de sus placas de marca/modelo;
- frecuencia y duración posibles;
- ejercicios actuales, cargas, repeticiones y RIR;
- molestias o movimientos mal tolerados;
- preferencia entre desarrollo global de pierna y mínima hipertrofia adicional de muslo;
- máquinas que resulten cómodas, incómodas o siempre ocupadas.

No se necesita esta información para iniciar G2. Sí será necesaria antes de declarar que una variante concreta es óptima para el usuario.
