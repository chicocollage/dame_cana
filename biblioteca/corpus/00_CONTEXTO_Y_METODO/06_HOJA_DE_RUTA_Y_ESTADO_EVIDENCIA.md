## Semáforo actual

**Entrenamiento especializado: verde.**

La anatomía, dosificación, matriz de 22 ejercicios, redundancias, sustituciones, progresión, nutrición, sueño, torso y compatibilidad con cardio están recopiladas. El paquete integrado 1.1 puede exportarse al chat de aplicación para construir el primer bloque personal.

> **HITO ENTRENAMIENTO: LISTO PARA EXPORTAR**

Ya no es necesario investigar más entrenamiento básico antes de comenzar un bloque conservador. El chat de aplicación deberá disponer de rutina actual, material, horarios, tendencia corporal, sueño y antecedentes de dolor.

**Cuidados estéticos: verde con diagnóstico personal pendiente.**

La rutina mínima, ramas por problema, incompatibilidades, señales médicas y matriz de 21 intervenciones están recopiladas. El paquete de cuidado estético 1.0 puede exportarse. Antes de elegir una rama deben conocerse el aspecto de las lesiones, síntomas, depilación, fototipo, productos y presupuesto.

> **HITO CUIDADO ESTÉTICO: LISTO PARA EXPORTAR**

**Seguimiento visual: verde.**

El protocolo neutral y la serie posada están separados; se han fijado vistas, cámara, distancia, luz, ropa, pose, vídeo y reglas de interpretación. La línea base puede tomarse al comenzar el bloque y repetirse cada cuatro semanas.

> **HITO SEGUIMIENTO VISUAL: LISTO PARA EXPORTAR**

**Sistema integrado: verde.**

T08–T12, programación avanzada, mantenimiento, microseries, potencia, descarga, asimetrías y antropometría están sintetizados. Existe una biblioteca completa y un paquete maestro autónomo.

> **HITO SISTEMA INTEGRADO 1.0: LISTO PARA EXPORTAR**

## Criterio para pasar entrenamiento a verde

Deben estar resueltas, como mínimo:

- T01–T06;
- una dosis inicial defendible;
- una matriz doméstica y de gimnasio;
- reglas de progresión y fatiga;
- contraindicaciones y sustituciones;
- una exportación comprensible para el chat de aplicación.

## Criterio para pasar cuidados a verde

Deben estar resueltas, como mínimo:

- E01–E08;
- rutina mínima y variantes según problema;
- incompatibilidades y escalado de activos;
- señales de derivación médica;
- comparación de coste, mantenimiento y duración del efecto.

## Entregas parciales

La fase 7 emite el paquete maestro 1.0 y cierra la investigación estructural. La fase 8 se dedicará a actualizar evidencia y auditar resultados personales.

El sistema 1.0 continúa en verde. El anexo ya dispone de matriz y programación. La selección de un modelo concreto sigue dependiendo de la prueba de encaje individual; G5 solo reunirá el paquete exportable.

> **HITO GIMNASIO — MATRIZ LISTA PARA PERSONALIZAR**

La matriz distingue evidencia, utilidad práctica, fatiga y crecimiento colateral. La elección de un modelo concreto requiere completar la prueba de encaje con el equipamiento real. G4 añade programas de dos, tres y cuatro días sin aumentar automáticamente el volumen al elevar la frecuencia.

> **HITO GIMNASIO — PAQUETE LISTO PARA EXPORTAR**

La carpeta no comprimida contiene síntesis, programas, selector, cuestionario personal, estudios, conclusiones, herramientas y manifiesto de integridad.
